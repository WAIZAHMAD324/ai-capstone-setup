## Project Rules (Learned from AI Workflow Drill)

1. All forms must include explicit validation rules and automated tests.
   - Required fields must have inline error messages.
   - Submit button must be disabled when invalid.
   - Validation must be covered by unit tests.

2. No feature should exceed its defined scope.
   - If the task is a single form, do not generate dashboards, themes, or extra UI systems.
   - Avoid adding unrelated sections unless explicitly specified.

3. Every AI-generated feature must pass verification steps:
   - Run lint
   - Run tests
   - Run production build
   - Do not merge code that has not passed all three.

4. Accessibility is mandatory:
   - All inputs must have labels with htmlFor and matching id.
   - Error messages must be readable text (not only color indicators).
