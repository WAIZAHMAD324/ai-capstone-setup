# Portfolio (Waiz Ahmad)

A minimal, clean frontend portfolio layout.

## What’s inside
- `index.html` — single-page portfolio structure (Work / About / Contact)
- `styles.css` — simple design system (dark UI, consistent spacing, cards)
- `assets/img` — place screenshots or project images here

## How to run
Just open `index.html` in your browser.

## Design notes (judgment rules)
- Keep it simple: 1 accent color, 1 font family, consistent spacing
- The design frames the work; it should not compete with it
- Prefer real screenshots of your work over AI images when showing proof
