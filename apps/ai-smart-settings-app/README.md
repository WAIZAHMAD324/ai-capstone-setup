AI Smart Settings App
A modern, production-quality Settings page built using React (Vite) with AI-assisted development and professional workflow practices.

🚀 Project Overview
This project demonstrates structured AI-assisted development with constraint-driven prompting, manual review, and verification practices.

The application includes:

✅ Real-time form validation
✅ Password confirmation matching
✅ Disabled submit button when invalid
✅ Success message on valid submission
✅ Data persistence using localStorage
✅ Dark/Light mode with persistence
✅ Modern premium UI using Tailwind CSS
✅ Automated tests using Vitest & React Testing Library
🧠 AI Development Workflow
AI was used as a development assistant — not as an uncontrolled code generator.

The workflow included:

Writing structured prompts with strict constraints.
Reviewing AI-generated output before implementation.
Manually improving UI and architecture.
Fixing environment issues (Tailwind version conflict).
Adding automated testing.
Verifying behavior with test runs.
This demonstrates controlled and responsible AI usage.
